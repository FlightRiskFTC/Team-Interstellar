## Instructions 

### Prerequisites

Download and install Android Studio and GitHub Desktop.

### Cloning the Repository

Click the green Code button in the repository, select HTTPS, and copy the URL.
Open GitHub Desktop, select Clone Repository, paste the URL, and clone the project.

### Setting Up Android Studio

Open Android Studio, click Open, and select the cloned Team Interstellar folder (do not move this folder).
If you are struggling to find the folder, search for the file in files.
Create a personal working branch: click the main branch dropdown at the top, select New Branch, and name it after yourself.
Sync and build the project using the Gradle Sync (elephant icon) and Build (hammer icon) buttons in the top toolbar.
Start editing code safely on your new branch.
